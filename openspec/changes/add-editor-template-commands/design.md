# 原子模板插入命令设计

## 公共边界

- 在工具栏插件公开纯编辑 helper 与可选命令插件。
- 所有选区一次事务处理并保留主选区，工具栏插件的默认按钮不变。

公共引擎 API 与工具栏、搜索插件的默认 UI 保持兼容，新增引擎能力仍由宿主显式接入。Electron 默认演示展示本轮公共能力，不需要独立开关；这不改变库在其他宿主中的默认行为。公共入口与类型必须可被原生 DOM、React、Vue 或无 DOM 的 Node 纯逻辑消费者使用；DOM 能力仍需目标 Document。文件授权、存储策略和 UI 属于宿主，不对插件隐式扩大权限。

## 运行与验证

复用现有插件生命周期和事务服务。异步任务绑定来源、版本和取消信号；Worker 硬取消与同步/DOM 回调的协作取消分别说明。按需声明依赖并检查正式发布版本、许可与运行环境。每个能力通过单元、公共入口消费、类型、构建和必要的真实 Electron 测试后再验收。

# Command palette demo

Search **UI actions** (not document text) — like VS Code `Ctrl+Shift+P`.

## How to open

1. Press **Ctrl+Shift+P** (macOS: **⌘⇧P**), or
2. Click the **⚡** button in the top toolbar.

## Try these queries

| Type | Opens / runs |
|---|---|
| `theme` / `dark` | Switch light ↔ dark theme |
| `preview` / `source` | Toggle Live Preview preference |
| `settings` | Open the settings panel |
| `outline` / `vault` / `backlink` | Toggle side panels |
| `find` | Document search bar (Ctrl+F) |
| `save` | Save current file |

Use **↑ / ↓** to move, **Enter** to run, **Esc** to dismiss.

> Tip: document text search is still **Ctrl+F**. The command palette finds *features and buttons* when you forget where they live.

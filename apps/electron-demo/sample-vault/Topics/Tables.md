# Tables

Interactive GFM tables render as editable cards in Live Preview.

## Sample

| Feature | Status | Notes |
| --- | --- | --- |
| Cell edit | Done | Click a cell to type |
| Column drag | Done | Use the column grip |
| Insert via slash | Done | Type `/table` |

## Try it

1. Place the caret on a blank line
2. Type `/table` and press Enter
3. Fill in the header cells

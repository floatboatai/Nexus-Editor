## 重要发现

1. **代码块无 `.nexus-code-block` 类**：普通代码块走 line decorations + marks（`<pre>` 不存在于 CM6 文本 DOM），仅 fence 行在光标外时 `color: transparent`。复制按钮 `button[aria-label="Copy code"]` 是唯一代码块"能力入口"标记。
2. **fence 行透明检测**：fence mark 的 `style.color` 在光标外为 `"transparent"`，光标内为 `"var(--nexus-text-faint,#bbb)"`。测试 F01 需通过 `.cm-line span` 文本匹配 `"```js"` 定位。
3. **代码块位置 0 边界**：若文档以代码块开头，`setSelection(0)` 光标实际落在块内（selectionIntersects inclusive）。测试需在块前加前导文本。
4. **mermaid 动态 import mock**：`vi.mock("mermaid")` 需先解决解析（pnpm 隔离 → alias `packages/core/node_modules/mermaid`）+ `server.deps.inline: ["mermaid"]`，否则加载真实 mermaid（E02 曾显示真实 "Parse error on line 3"）。
5. **行内链接交互为 mousedown + window.open(url, "_blank", "noopener")**：与默认 link renderer 的 click+ctrlKey 路径不同，data-link-url 标记走独立事件委托（mousedown）。
6. **HTML 块清洗语义**：script 整体移除、on*/javascript: 中和（a.href → "#"）、iframe/object/embed/style 移除、注释走 `.nexus-html-comment` 文本路径。
7. **jsdom 自带 window.alert**：断言脚本未执行不能用 `window.alert === undefined`，需 `vi.stubGlobal("alert", spy)`。

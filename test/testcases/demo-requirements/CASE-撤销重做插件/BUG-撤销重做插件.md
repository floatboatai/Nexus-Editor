## BUG-01：N09 用例断言与 CM6 Delete 语义不符（测试脚本问题，非产品缺陷）

- **关联用例**：FP-14-01-N09
- **严重程度**：低
- **发现时间**：2026-08-11
- **测试框架**：Playwright

- **现象**：用例预期输入 "ABC" → 删除 B → 输入 X 后文本为 "ACX"，实际得到 "AXC"，测试断言失败。
- **复现步骤**：
  1. 输入 "ABC"
  2. Home → ArrowRight（光标位于 B 前）
  3. Delete 删除 B
  4. 输入 "X"
- **预期结果**（用例文档）："ACX"（假设 Delete 后光标跳至文末）
- **实际结果**：CM6 中 Delete 删除后光标停留在删除位置（`A|C`），输入 X 得 "AXC"
- **影响范围**：仅 FP-14-01-N09；已通过修正断言为 "AXC" 解决，撤销/重做行为验证不受影响
- **可能原因**：用例文档编写时假设 Delete 后光标移动到文末，与 CM6 编辑器真实光标语义不符。属于测试脚本断言问题，非产品 BUG。
- **临时解决方案**：断言改为验证 "AXC"；撤销 X 后验证恢复 "AC"，撤销 Delete 后验证恢复 "ABC"（保持原测试意图）。

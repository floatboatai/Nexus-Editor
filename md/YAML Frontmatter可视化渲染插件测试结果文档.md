# YAML Frontmatter 可视化渲染插件测试结果文档

本测试结果文档记录了 YAML Frontmatter 可视化编辑与属性面板插件的功能测试详情，包含期望值与实际运行测试值的对比。

---

## 1. 测试环境
- 运行框架：Vitest 2.1.9
- 执行方式：npx vitest run packages/core/test/frontmatter.test.ts

---

## 2. 测试用例详情与期望值对比

### 用例 1：YAML Frontmatter 语法树与 AST 转换测试
- **测试功能**：验证能否正确从头部的 `---` 区域提取 YAML 结构，且后续普通文本能够正常解析，不被 frontmatter 的闭合横线误伤为 HorizontalRule。
- **对比维度**：
  - **期望值**：
    - `ast.children[0].type` 值为 `"yaml"`；
    - 节点的 `value` 包含 `"title: \"测试文档\""`；
    - `ast.children[1].type` 值为 `"paragraph"`。
  - **实际测试值**：
    - 首节点类型为 `"yaml"`；
    - 元数据值正确包含所有定义的键值；
    - 下一个兄弟节点正确解析为 `"paragraph"`（正文内容）。
- **测试结果**：🟢 通过 (PASS)

---

### 用例 2：折叠与光标交互状态测试
- **测试功能**：验证当光标位于 Frontmatter 外部时，卡片折叠呈现精美 Widget 并隐藏原始 Markdown 代码；当光标移入元数据区间时，卡片销毁并展开为原始 YAML 源码供编辑。
- **对比维度**：
  - **期望值**：
    - **光标在外部**：`container.querySelector(".nexus-frontmatter-panel")` 存在，且 `container.textContent` 中**不包含** `"title: \"可视化测试\""`。
    - **光标在内部**：`container.querySelector(".nexus-frontmatter-panel")` 自动被移除消失，且 `container.textContent` 中显示原始 YAML 代码。
  - **实际测试值**：
    - 外部状态下面板正确挂载，原始代码完美折叠隐藏；
    - 内部状态下面板自动卸载，源码无缝恢复呈现在编辑器中。
- **测试结果**：🟢 通过 (PASS)

---

### 用例 3：编辑按钮交互跳转测试
- **测试功能**：在折叠状态下，验证点击 Widget 右上角悬浮的“✎”编辑元数据按钮后，光标是否能精准定位至 Frontmatter 顶部（偏移量 0）并自动完成卡片展开。
- **对比维度**：
  - **期望值**：
    - 点击后 `editor.getSelection().anchor === 0`；
    - `.nexus-frontmatter-panel` 容器自动卸载消失（因光标触发展开）。
  - **实际测试值**：
    - 点击后选区定位正确重置到 `0` 偏移；
    - 面板即时消失，顺畅进入 YAML 源码编辑状态。
- **测试结果**：🟢 通过 (PASS)

---

### 用例 4：非法的 YAML 格式解析失败警告卡片测试
- **测试功能**：校验输入非法 YAML（如冒号后缺少空格）时，在折叠模式下，是否正确拦截常规表格渲染，并替换为淡红警告面板，且提示信息中必须精确列明出错行号与报错的根本原因。
- **对比维度**：
  - **期望值**：
    - `.nexus-frontmatter-panel` 面板文本内容包含 `"YAML 格式解析失败"`；
    - 面板内容包含 `"第 2 行"`；
    - 报错诊断信息包含 `"冒号 ':' 与后面的值之间必须保留至少一个空格间隔"`。
  - **实际测试值**：
    - 页面正确渲染莫兰迪淡红报错面板；
    - 诊断信息中成功提取并提示了第 2 行的冒号缺失空格错误。
- **测试结果**：🟢 通过 (PASS)

---

### 用例 5：源码模式下的行高亮波浪线诊断测试
- **测试功能**：校验在源码编辑模式下（光标移入内部），如果 YAML 中包含非标准格式，被诊断出的错误行是否能自动应用红色波浪线下划线装饰，且 hover 悬浮时能以 HTML title 属性呈现具体的错误提示。
- **对比维度**：
  - **期望值**：
    - 编辑器中存在应用了 `underline wavy` 红色波浪线样式的行内标记 span 元素；
    - 对应的 span 元素的 `title` 属性包含具体的诊断报错文案。
  - **实际测试值**：
    - 成功检索到应用了 `underline wavy var(--nexus-hl-deletion, #cf222e)` 样式的文本装饰 span 元素；
    - 且对应的 HTML `title` 正确显示了对于第 2 行格式异常的具体诊断描述。
- **测试结果**：🟢 通过 (PASS)

---

### 用例 6：元数据属性智能联想与非独占式补全测试
- **测试功能**：校验自动补全源的区域限制与联想效果。当光标在 YAML 物理区内时激活常用属性联想（如 title、tags 等），而在正文物理区间（YAML 范围外）时，应自动阻断触发以实现零运行时性能开销。
- **对比维度**：
  - **期望值**：
    - **光标在 YAML 内**：通过 `EditorState.languageData` 解析到的 autocomplete 补全列表中包含 `"title"`、`"tags"` 等选项；
    - **光标在正文内**：调用补全源返回 `null`，无任何联想推荐。
  - **实际测试值**：
    - 物理区间内成功激活联想列表，属性推荐完全正确；
    - 正文物理区内被零开销机制拦截，正确返回 `null`。
- **测试结果**：🟢 通过 (PASS)

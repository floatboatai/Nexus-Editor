> 关联 Roadmap：#17
> 优先级：P2
> 归属包：`@floatboat/nexus-plugin-search`
> 分支：`feat/search-fuzzy-support`
> 开始时间：2026-07-13

---

## 一、目标

为 `@floatboat/nexus-plugin-search` 增加模糊搜索能力。用户输入 `hw` 可以匹配 `hello world`，并高亮匹配位置。该功能默认关闭，通过 `SearchOptions.fuzzy` 开启，保持现有正则/全字匹配行为完全向后兼容。

---

### 必须实现（MVP）

- [ ] 新增 `fuzzyMatch(query, text)` 函数，支持字符跳跃匹配
- [ ] 返回匹配位置数组，供后续高亮使用
- [ ] 实现评分体系，对结果排序
- [ ] 在 `SearchOptions` 中新增 `fuzzy?: boolean` 选项
- [ ] 当 `fuzzy=true` 时，搜索面板和 `findNext/findPrevious` 使用模糊匹配

- [ ] 新增单测覆盖核心算法和边界情况
- [ ] 全量测试、构建、类型检查通过

### 3.2 核心算法设计

```
fuzzyMatch("hw", "hello world")
→ {
    matched: true,
    positions: [0, 6],  // h 和 w 的位置
    score: 120,
}
```

评分维度：

| 维度 | 分值 | 说明 |
|---|---|---|
| 完整匹配 | +1000 | query 每个字符都找到 |
| 连续匹配 | +100/字符 | 如 `he` 连续匹配 hello |
| 词首匹配 | +50/字符 | 空格后或首字符 |
| 短距离跳跃 | +10/字符 | 相邻字符距离越近分越高 |
| 原始顺序 | 基础分 | 按字符在原字符串中的顺序匹配 |

### 3.3 集成点

在 `plugin-search/src/index.ts` 中：

- `SearchOptions` 增加 `fuzzy?: boolean`
- `buildSearchPattern` 函数增加 fuzzy 分支
- 当 `fuzzy=true` 时，不使用 `RegExp`，改用自定义匹配逻辑遍历文档
- 匹配结果通过 `SearchMatch[]` 返回给调用方

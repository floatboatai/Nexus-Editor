## Nexus-Editor bug 排查与修复

- 根因排查：本机 Windows 无符号链接权限（非管理员/未开开发者模式），`fs.symlink()` 创建的文件符号链接是死链接（lstat/stat 全 ENOENT），目录链接必须用 `junction` 类型。
- 修复 `apps/electron-demo/test/plugin-host-broker.test.ts`（9 个安全测试失败）：新增 `symlinkDirectory`（win32 用 junction）与 `swapLeafOutside`（win32 用硬链接）辅助函数；O_NONBLOCK 断言加 `undefined` 守卫；in-vault symlink 测试在 win32 用 `NotesAlias` junction 变体。
